SAHAYAK v83 - Syllabus PDFs are now read automatically. NO database change. ONE new software package (unpdf).
1. Unzip over your project (it includes package.json and package-lock.json), commit, let Vercel deploy. Vercel installs the package by itself.
2. Admin > Curriculum and syllabus > upload a syllabus PDF. Open the new draft: the items read from the PDF are listed with their PDF page numbers. CHECK THEM against the PDF, fix or flag, then approve and publish as before.
HOW IT READS: only lines that start with Unit, Section, Chapter, Topic, Learning outcome or Assessment objective (for example "Chapter 2: Polynomials") become items. Everything else is left out, never guessed. A PDF made of pictures (scanned) has no text: you are told, the file is still saved, and you paste the outline or use the CSV template.
TESTED: new test t83 (15) using real PDFs including a picture-only one and a broken one; all earlier tests pass; type check clean; full production build clean; the built server read the test PDFs correctly.
NOT TESTED: with your real CBSE syllabus PDF (tables and unusual layouts may give fewer items); on Vercel itself; signed-in upload.
NOT BUILT: reading scanned PDFs (OCR); reading tables inside PDFs.
NOT DEPLOYED: nothing is deployed from here.
