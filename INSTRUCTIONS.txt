SAHAYAK - v64 UPDATE
Apply v63 (and everything before it) first.

WHAT THIS UPDATE DOES
1. WEBSITE TRAFFIC (Admin > Website traffic, /admin/traffic). Like a simple Google Analytics: visitors, sessions, page views, pages per session, bounce rate, average session length, a daily chart, top pages, landing pages, how people arrive (direct, search, social, WhatsApp/Telegram, other websites, campaigns), devices, browsers, countries, signed-in or not, and "people on the site right now" (last 5 minutes). Choose Today / 7 / 30 / 90 days; each figure shows the change against the period before when there is enough data. It also shows how many accounts were created and how many diagnostics were finished in the same period.
   - Privacy: it uses NO cookies and stores NO IP address, name or browser string. A visitor is an anonymous code that changes every day. Visits from bots, from browsers that send "Do Not Track", and your admin pages are not counted. The privacy policy has a new line about this (the Hindi sentence is a draft for a Hindi teacher to read).
   - Because the code changes daily, "Visitors" means different browsers per day, added up. Someone who returns tomorrow counts again. The page says this. It cannot tell you how many different PEOPLE visited.
   - To see where your shared links work, add ?utm_source=whatsapp (or any name) to the link, e.g. https://yoursite/?utm_source=school-group.
   - Counting starts the day you deploy. Nothing earlier is available.
2. PLANS & PRICING MENU. A yellow "Plans & Pricing" button is in the top menu on every page for everyone (signed in or not, students, parents, teachers, admin). It opens a dropdown: Free plan (1 subject), Founding Family, Subject plans, Handwritten mock, Tutors & centres, Compare features. Each goes to the right part of the Plans page. On a phone the same list is in the menu. No price is typed in the menu; prices still come from Admin > Pricing.
3. FREE PLAN = 1 SUBJECT, in bold on the diagnostic subject picker: "Free plan: 1 subject per account." It says that the subject started first becomes the free subject, and once one is chosen it names it and greys out the other subjects with "Paid plan" and a link to the plans. (The real limit was already enforced by the server; this only explains it.)
4. NEW LOGO AND TAGLINE. Your artwork was cut out onto a transparent background and is used in the header (artwork only), on the home page (full logo with the tagline "Measure Your Growth, Master Your Subjects."), in the browser tab icon, phone icon and when the site is shared.

STEPS
1. Unzip over your project folder (replace files). This zip includes apps/web/app/layout.tsx (it now loads the traffic counter).
2. npm install
3. npm run db:migrate   (adds migration 0041; safe to run twice)
4. OPTIONAL: on Vercel add an environment variable ANALYTICS_SALT with any long random text, then redeploy. Without it a safe default is used.
5. Deploy as usual. Visit your site a few times, then open Admin > Website traffic.
