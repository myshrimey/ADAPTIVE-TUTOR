WHAT THIS UPDATE DOES
Students now get a short, mixed review of skills that are DUE, planned from the answers they already gave. This helps them remember, not just learn once.
1. A skill is shown again after 1, 3, 7, 14, 30 and 60 days. If the student gets it right when it is due, it waits longer. If they miss it, it comes back sooner.
2. Ten questions in one evening count as ONE day, so cramming does not push the next review far away.
3. From 21 days before the Board exam date (the date you entered under Boards, exams, country prices) the page switches to "Exam revision". No review is ever planned after the exam starts. If you have not entered the date, this simply does not apply.
4. The "Revise today" page (menu: Learn > Revise today, and a button on Today) shows: skills due today, due in the next 7 days, and long-gap skills. It starts a short session of up to 6 questions (10 near the exam), one per skill, mixed across chapters. Questions the student has not seen come first. Answers are checked on the server; the answer key is never sent to the browser.
5. No marks, ranks or labels are shown. English and Hindi.
6. Migration 0044 (one new table). Safe to run twice. No AI is used, so no AI cost.

STEPS

2. npm install
3. npm run db:migrate   (adds 0044)
4. Deploy as usual.
5. Sign in as a student who has done some practice or quiz; open Revise today. A brand-new student will see "Nothing to revise yet" - that is correct.
