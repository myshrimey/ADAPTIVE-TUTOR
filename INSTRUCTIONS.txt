SAHAYAK - v74 UPDATE  (report a problem with a question)
Apply v73 first. NO database change.

WHAT IT DOES
Under the question on the Baseline, Challenge, Stretch and Review screens there is now a small grey link: "Something wrong with this question? Tell us" (Hindi on Review for Hindi students). It opens the normal Feedback form with "A problem with a question" already chosen and the question's id attached. In /admin/feedback-intelligence the report is grouped as usual and the question id is kept with it (a wrong-answer report is lifted for review by the v73 rules).
It sends nothing by itself; the student still writes a sentence and presses Send.

STEPS
1. Unzip over your project folder.  2. npm install  3. Deploy. (No db:migrate.)

TESTED: type check and full production build.
NOT TESTED: on your live site or a phone.
