SAHAYAK - v73 UPDATE  (Feedback Intelligence: the rest of your prompt)
Apply v72 (and everything before it) first. ONE database change (0047).

WHAT ALREADY EXISTED (v67) AND IS KEPT: the Feedback button, sorting of messages into groups by plain rules, the review page, Approve/Reject/Modify/Investigate/Defer with history, and the extra care for risky areas. Nothing was replaced.

WHAT IS NEW
1. The Feedback button now also asks (both optional): what it is about, and how it affected you (minor inconvenience ... serious problem). Behind the scenes it records the page, who it is (student / parent / tutor / centre / visitor, worked out from the page and the student sign-in, never trusted from the browser), device, browser, language, app version and plan. If the database update has not been run yet, the message is still saved the old way: feedback is never lost.
2. Page /admin/feedback-intelligence:
   - Tiles: total, open groups, critical (P0), high (P1), new this week, repeats, approved, implemented, awaiting validation, reopened. A "Top problems / quick wins / strategic / learning-critical / money-critical / top loved features / numbers" section.
   - "Add feedback you received outside the app": calls, meetings, WhatsApp, email, social, school or centre talks. It is sorted and grouped like any other feedback.
   - Search (also inside the messages), filters (kind, feature, who, source, priority, moat value) and sorting.
   - Every group shows a priority P0-P3 with "Why?": a plain sum of 7 lines (severity, people affected, last-7-day reports, effect on learning, money/trust, what reporters said about the effect, moat value). Possible wrong answers or marking, privacy words, diagnostic problems and payment trouble are lifted automatically and the reason is written. You can change the priority by hand; a reason is required and it is recorded.
   - Moat value tag (none ... core).
   - "Ask AI to analyse (optional)": a labelled RECOMMENDATION (summary, suspected cause, suggested solution, confidence, reasoning). It never approves, rejects or changes anything. It uses the same AI system as the rest of the app (cost appears under feature "feedback_analysis"), personal details are removed first, and it is limited to 30 a day. If the AI fails, nothing is lost.
   - For approved groups: write a product task (problem, expected result, how we will know it is fixed, who, target release). For implemented groups: record whether the fix worked (fixed and validated needs the version or date it went live; not fixed / regression reopens the group).
   - Defer now accepts a "review again on" date.
