SAHAYAK - v70 UPDATE  (step-by-step help that fades + mixed practice)
Apply v69 (and everything before it) first. NO database change this time.

WHAT THIS UPDATE DOES
1. HELP THAT FADES AWAY. In the tutor chat, how much help Sahayak gives is now decided by fixed rules, in five steps:
   1 a full worked example, every step explained  ->  2 a worked example with a step or two left blank  ->  3 the student does the steps with a small guiding question  ->  4 the student tries alone, a hint only if asked or after a mistake  ->  5 no help unless asked.
   A new skill starts at step 1. The step comes from how well the student already knows that skill. Two clean answers in a row (right, no hints) remove one step of help. A wrong answer, or a right one that needed a hint, puts one step back. Two wrong in a row goes back to a worked example. A "test myself" session is step 5.
   The rule is passed to the tutor as one extra instruction line ("Support: ..."). It does not change marks, mastery, difficulty or which questions are asked.
2. OPTIONAL MIXED PRACTICE on the "Revise today" page. After the daily review, a student with at least three secure skills sees "Optional: mixed practice": up to 6 questions on skills they already handle well, mixed from different chapters (switching topics is harder, and that builds stronger memory). Skills still being learned or recently forgotten are left out. It does not move review dates unless the student misses a question.
3. The Admin "What is built / not built" page is updated.
No AI is used by the new rules, so no new AI cost.

STEPS
1. Unzip over your project folder (replace files).
2. npm install
3. Deploy as usual. (No npm run db:migrate needed.)
4. Try: start a learning session on a new skill: the first tutor message should show a full worked example. Then answer a few questions correctly with no hints; the tutor should give less help.
