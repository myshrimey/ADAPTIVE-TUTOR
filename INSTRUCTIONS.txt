SAHAYAK v116 - paper library accepts only PDFs up to 10 MB   (SECURITY FIX)
Apply after v115: unzip over the project, run the database change below, then deploy as usual.

WHY
- The shared paper library (/papers) is a PUBLIC storage area. Any signed-in account (free self-sign-up included) could upload any file of any type and size, and it was listed to everyone at once. Nothing checked the file path saved with it either.

WHAT CHANGES
1. Only PDF files up to 10 MB: checked on the page (friendly message), on the save route (the real check), and by the storage area itself.
2. DATABASE: run packages/db/migrations/0062_papers_bucket_limits.sql (npm run db:migrate runs it). It only sets two settings on the "papers" storage area; no table changes; safe to run twice.
3. After deploying, open /admin/deploy-check and run the new 0062 line under "checks you paste by hand". Expect one row: papers, 10485760, {application/pdf}.

TESTED

Full suite: 93 files, 89 passed, 4 known-old, 0 failed. Production build compiled; the save route answers "unauthenticated" for a signed-out caller.
