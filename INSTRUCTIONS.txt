SAHAYAK — v23 UPDATE
Simple step-by-step guide. Do these steps in order.

====================================================================
WHAT THIS UPDATE DOES
====================================================================

You asked for 7 things. Here's what each one became:

1. "Topic being covered visible on the left, with a progress bar"
   -> The /learn page now has a left sidebar that always shows: the
      subject, chapter, topic, and skill the student is currently
      being taught, plus a progress bar for how much of that skill
      they've already mastered, plus a running "X/Y correct this
      session" count.

2. "User's name visible everywhere when logged in"
   -> The header bar (top of every page) now shows "Hi, <name>" next
      to the navigation links, whenever the student is signed in.

3. "Learning session takes too long to load" and
4. "Switching between progress and learning takes time"
   -> Found and fixed the real cause: the code that loads your
      curriculum (subjects/chapters/topics/skills) was making roughly
      150+ separate, one-at-a-time requests to the database every
      single time a page needed it — once per chapter, once per topic,
      once per skill, once per skill's prerequisites. That function
      runs on nearly every page load. It's rewritten to do the same
      job in about 6 database requests total, no matter how big the
      curriculum gets. This is the single biggest speed fix in this
      update. A couple of smaller spots (starting a session, loading
      the dashboard) were also changed to run their independent
      database checks at the same time instead of one after another.

5. "Take a diagnostic test any time from any location"
   -> Added a "Take a test" link to the header bar, next to "Progress"
      and "Learn" — visible on every page, not just during onboarding.
      Clicking it always starts a fresh diagnostic test.

6. "A small quiz after every learning session, with answers,
   solutions, and grading"
   -> When a student clicks "End session" now, before the usual
      summary screen, they get a short 5-question quiz on the skill
      they just learned (a mix of question types, pulled from the
      same large question bank you already have — no new content had
      to be written). After submitting, they see their score, and for
      every question: whether they got it right, the correct answer,
      and the explanation (where one exists in the question bank).
      There's a "Skip quiz" option too, so nobody gets stuck.

7. "Animations, infographics, exciting colors to make it visually
   attractive"
   -> Added smooth fade-in animations for chat messages and quiz
      cards, a bouncing "typing…" indicator instead of a static "…",
      a colorful gradient progress bar, a celebratory animated score
      banner after the quiz, and a small lift effect on buttons when
      hovered. Kept your existing color palette and fonts — this is a
      polish pass, not a redesign, so it won't feel like a different
      app.

Nothing about Maths/Science question content changed in this round —
this was entirely about the learning experience, performance, and
visuals.

====================================================================

Unzip this file. You'll see a folder structure. Copy EVERY file from
inside this unzipped folder into your real project folder, keeping
the same folders, and REPLACING any file with the same name.

file across into the matching folder. For the 3 new files, you'll
need to create the folders first if they don't already exist
(apps/web/app/api/quiz/start/, apps/web/app/api/quiz/submit/,
packages/core/quiz/) — just make a new folder with that exact name
in the right place, then put the file inside it.

====================================================================
STEP 2 — Build it to make sure nothing's broken
====================================================================

Open your command prompt in your project folder and run:

    npm install
    npm run build

Wait for it to finish. It should end with a list of routes and no
red "Failed to compile" message. (I already ran this exact build on
my end after making these changes and it passed cleanly — this step
is just to confirm it also works in your copy of the project.)

If you see an error, copy-paste the FULL error text back to me and
I'll tell you exactly what to fix.

====================================================================
STEP 3 — Commit and push
====================================================================

Still in your command prompt, run these one at a time:

    git add .
    git commit -m "v23: sidebar + progress bar, visible username, faster loading, universal diagnostic access, post-session quiz, visual polish"
    git push

If it asks you to pull first, just run "git pull" then try the push
again.

====================================================================
STEP 4 — Check it on the live site
====================================================================

Vercel will redeploy automatically after the push (usually 1-3
minutes). Then:

  1. Hard-refresh the site (Ctrl+Shift+R) so you're not looking at an
     old cached version.
  2. Sign in and look at the header — your name should now show up
     next to "Progress" / "Learn", and there should be a new
     "Take a test" link.
  3. Click "Take a test" from somewhere OTHER than onboarding (e.g.
     from the dashboard) — it should start a diagnostic test right
     away.
  4. Go to "Learn" and start a session — you should see the new left
     sidebar with the subject/chapter/topic/skill and a progress bar.
     Notice whether the page feels faster to load than before.
  5. Answer a couple of questions, then click "End session" — you
     should land on a short quiz before the usual summary screen.
     Answer it (or click "Skip quiz") and confirm you see a score and
     explanations.
  6. Switch back and forth between "Progress" and "Learn" a couple of
     times and see if it feels noticeably snappier than before — it
     should, especially once Vercel's cold start has passed (the very
     first load after a deploy is always a bit slower regardless).

====================================================================
A NOTE ON THE QUIZ CONTENT
====================================================================

The post-session quiz pulls straight from your existing diagnostic
question bank (same questions used for the placement test), filtered
to just the skill that session covered. Most questions already have
an explanation written; a few of the older ones don't, so for those
the student will just see "correct answer" without a written
explanation. That's existing content, not something this update
needs to fix — if you want, a future round could add explanations to
whichever questions are still missing them.
