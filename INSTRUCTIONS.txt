SAHAYAK v56 - Two exams (Board 1 / Board 2) and four separate languages

BEFORE YOU START
1. Apply the v55b zip first (sahayak-v55b-ai-gateway-delta.zip) if you have not.

HOW TO APPLY
1. Unzip this folder on top of your project folder. Say yes to replace files.
2. Open a terminal in the project folder and run:  npm run db:migrate
   (this adds migration 0033; it is safe to run again)
3. Push to GitHub / deploy to Vercel as usual.

WHAT YOU CAN DO NOW
- Admin > Pricing > "boards": type the two exam dates, names, and (optionally) which subjects each exam covers. Until you do, the app shows "Exam date not set yet" and never guesses a date.
- Students: Profile page has four language choices: App, Question, Learning (tutor replies), Report.
- Board Readiness and the Preparation Programme now show Board 1 and Board 2 side by side. They never predict marks. They say "Insufficient data" when there is not enough evidence.
- Admin > "Check Hindi translations": pick a subject, read the English and Hindi side by side, mark Correct or Wrong. A wrong one is never shown to students. "Re-run automatic checks" tests numbers, signs and options again.
- Admin > "Subject requests": see which subjects families ask for.
- Hindi or mixed-language handwriting is sent to a teacher unless the AI is very sure.
