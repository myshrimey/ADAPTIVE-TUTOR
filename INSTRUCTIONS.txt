SAHAYAK - v60 UPDATE
Simple step-by-step guide. Apply v59 (and everything before it) first.

WHAT THIS UPDATE DOES
1. Every diagnostic now has exactly 20 questions (no more "8-15"). If a student misses a question, a check on what it depends on replaces one of the extra questions, so the total stays 20. A diagnostic a student already started keeps its old length.
2. Every answer box (diagnostic, quiz, practice chat, mock paper, challenge, written answers) now stops the wrong kind of typing. A number answer will not accept letters; a word answer will not accept digits. The student sees a short warning (English, and Hindi if the app is in Hindi). A "Symbols keypad" button opens a keypad with x squared, square root, pi, fractions, powers, less/greater-than, chemistry subscripts and arrows. Typed symbols are marked the same as plain text (x² = x^2, √3 = sqrt(3)).
3. Admin > Question bank growth: a "Fill to 1,000" button per subject with a progress bar, and a plain explanation of what "Owed" means. Computer Applications questions on logic, addresses, spreadsheets, loops, HTML and number systems are written by computer code (the answer is calculated, so it cannot be wrong, and it costs no AI). Other subjects use the AI plus a second independent check. All new questions are marked "needs review".
4. Referral links for everyone: students, parents, teachers, tutors, centres. The "Invite" box with Copy, WhatsApp and Share is on the homepage, dashboard, profile, parent/tutor/centre pages and the teacher page; sign-up pages say "You were invited". When the friend finishes a real first diagnostic (at least 10 answers), both get extra access days, once, automatically. Admin > "Referral links and rewards" shows counts and lets you set the days.

STEPS
1. Unzip over your project folder (replace files).
2. Run: npm install
3. Run: npm run db:migrate   (adds migration 0037; safe to run twice)
4. Deploy as usual.
5. Open Admin > Referral links and rewards. Type how many days each side should get, tick "Give extra access days automatically", press Save. Until you do this, invites are only counted and no days are given.
6. Open Admin > Question bank growth and press "Fill to 1,000" for each subject. Each press works for up to about 45 seconds; press again to continue. Computer Applications will move fastest.

NOT TESTED

NOT BUILT / THINGS TO KNOW
- This does NOT reach 1,000 questions by itself. Computer Applications, English, Hindi A and Hindi B, Social Science are far below; filling depends on how much free AI quota you have each day. Maths and Science are close. There are no code generators yet for English, Hindi or Social Science.
- Free-plan students cannot "use" extra days: their bonus days are kept and added when a paid plan is activated. If you want free-plan students to get a short paid-style trial instead, tell me.
- Teachers, tutors and centres are counted but not paid in days; their rewards wait at Admin > Referral links and rewards for you to settle by hand.
- Opening an invite link alone does nothing; the code is attached only when the new account is created.
