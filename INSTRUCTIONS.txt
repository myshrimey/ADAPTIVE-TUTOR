SAHAYAK v54 - plans, prices, offers, credits and offline (UPI) payment, all changeable without code
Apply AFTER v53.

HOW TO PUT IT ON THE WEBSITE
1. Unzip. Copy every folder/file over your project folder ("Replace" when asked).
2. Supabase: run the project's usual migration command (npm run db:migrate) OR paste packages/db/migrations/0029_commerce.sql into SQL Editor and press Run. SAFE to run twice. DO THIS BEFORE deploying, otherwise the new pages show empty plans.
3. Deploy to Vercel the usual way. No new environment variables.

THINGS ONLY YOU CAN DO (the app never invents these)
1. Open /admin/pricing > "payment_instructions" and type your UPI ID / QR text. Until then buyers see no payment details.
2. Same page > "economics": fill your own cost assumptions (AI cost per image, review cost, etc.). Until filled, the commercial dashboard says "insufficient data" instead of guessing a margin.
3. When you want the handwritten mock to need credits, switch ON "handwritten.credits_required" in /admin/pricing. It is OFF now, so nothing changes for existing users.
4. HOW TO CHANGE A PRICE: /admin/pricing > the product > edit price > Save. Offers/coupons: same page > Offers. Nothing needs redeploying.

WHAT TO CHECK (15 minutes)
1. Open /plans on your phone. All prices come from the database: Founding Family 7,999; subject plans 1,499 / 2,499 / 3,499 / 4,999 / 6,999; handwritten mock 499. Every card shows "Terms & Conditions Apply."
2. Sign in as a test student > pick a plan > buy page shows price and your payment instructions > submit a fake transaction reference.
3. /admin/payments shows the request with product, discount and subjects. Press "Verify payment and activate": the student gets the plan, subjects and credits. Pressing it twice must not double the credits.
4. Mock paper: upload more photos than the limit - it is refused with a clear message. Upload the same photo twice - refused.
5. /admin/commercial and /admin/interest show the numbers; Export buttons give CSV files.

IMPORTANT DIFFERENCES FROM EARLIER RULES (please read)
- Old prices (4,999 / 14,999) are replaced by the new pricing prompt. Old code constants remain but are no longer shown.
- Earlier rule "payment confirmation never grants access" is changed: the new button "Verify payment and activate" grants access, only when YOU press it. The old "Only record as paid" button still grants nothing.
- The 499 handwritten mock stays the list price; a 399 offer exists but is switched OFF.
