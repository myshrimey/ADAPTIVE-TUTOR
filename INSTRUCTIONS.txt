SAHAYAK - v69 UPDATE  (tutors and coaching centres: who needs attention)
Apply v68 (and everything before it) first.

WHAT THIS UPDATE DOES
Tutors and coaching centres get a new page, "Who needs attention, batches and interventions" (a button on their dashboard; the page is /tutor/attention or /centre/attention).
1. WHO NEEDS MY ATTENTION. Every linked student is placed in one of: Needs a conversation, Keep an eye, Going well, Ready for harder work, or Not enough information yet. Each shows the reasons (for example "has not practised for 16 days", "average mastery 35/100"), the facts behind it, and a suggested action (for example "a 20-minute guided session on Quadratics, then 3 short questions a few days later"). The order is: most in need first. These words are supportive on purpose. No marks are predicted and nobody is ranked against others. It is advice; the tutor decides.
2. BATCHES. Create a batch (for example "Class 10 evening"), tick which students belong to it. Each batch shows how many are active, the average, how many need a conversation, and gaps shared by two or more students (so a short group session can help).
3. INTERVENTIONS. For a student who needs attention, press "Plan an intervention": it fills in the problem, evidence and action for you to edit. When the tutor marks it done, then 5 or more days later the page compares the skill's score before and after and says: improved / not moved much / lower / too early to say. It shows what happened; it cannot prove the session was the cause, and it says so.
4. PRIVACY. A tutor or centre sees only students who gave THEIR one-time code. If a family cancels the link, the student disappears from boards and batches immediately. One tutor can never see or change another tutor's batches or plans (tested).
5. Migration 0045 (three new server-only tables). Safe to run twice. No AI, so no AI cost.
6. The "What is built / not built" page in Admin is updated.

STEPS
1. Unzip over your project folder (replace files).
2. npm install
3. npm run db:migrate   (adds 0045)
4. Deploy as usual.
5. Try it: sign in as a tutor (or centre) test account, link a test student with a code, open "Who needs attention, batches and interventions".

TESTED: about 40 checks on the attention rules, wording, batches, interventions and the privacy boundary (another tutor, a cancelled link, a bad id); older checks for v63-v68 still pass; type check and full build pass; migration 0045 ran twice on a test database.
