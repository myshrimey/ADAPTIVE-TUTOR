SAHAYAK v58 - ENGAGEMENT LEFTOVERS
==================================
Apply AFTER v57.

WHAT THIS ADDS
1. Hindi text on the engagement screens (Today, Challenges, Mistake Book, Achievements, Study journey, Weakness Battle, Challenge of the Day, My progress, class board, the round screen, the dashboard Today card and the Practice menu). Students see Hindi when their app language is Hindi.
2. Friend challenge: a student makes a challenge, shares an 8-character code with one friend, both play the same 5 verified questions. After both have played, each sees the other's NICKNAME and score. No chat, no names.
3. Invite a friend (referral): each student has a personal code. A new student can enter one code in their first 14 days. A code works 50 times at most. Nothing is paid, discounted or credited automatically.
4. Admin pages: "Referrals" (counts, and you set any reward by hand) and "Engagement experiments" (compares students who have a feature with those who do not).
Also fixed: tutor/centre challenge rounds were saved without their subject.

STEPS
1. Copy the folders "apps", "packages" and "docs", and the files CLAUDE.md and SAHAYAK_PROJECT_MEMORY.md, into your project folder. Choose Replace when asked.
2. Open a terminal in the project folder:  npm install
3. Run:  npm run db:migrate    (applies 0035, safe to run again)
4. Run:  npm run build, then push to GitHub so Vercel redeploys.
5. Friend challenge and Invite are OFF. To try them, open /admin/engagement-settings and tick "friend challenge" and/or "referral". Please read the privacy note on that page first: these are school-age students.
6. To compare a feature, set its "share of students" between 1 and 99 in the same page, then look at /admin/engagement/ab after a week or two.
