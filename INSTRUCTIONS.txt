Sahayak v136 - Contact book (delta on top of v135)

WHAT CHANGED
- New page /admin/contacts (Super Admin only). Lists every account with its full email, a phone, a WhatsApp number and a note. Edit in the row and press Save.
- Changing an email here also changes the email the person signs in with. If the second step fails the first is undone.
- Opening the page and every edit are written to the Audit log. The log names which fields changed, never the numbers or emails.
- Family Profile page has a new "Parent WhatsApp number" field. What families enter shows in the Contact book (read-only there).
- Menu entry "Contact book" in the admin menu.
- Migration 0067: new column student_profile_details.parent_whatsapp and new server-only table user_contacts.

ORDER
1. Copy the files over your project and deploy the website.
2. Run npm run db:migrate (0067 is new; the v135 fix means earlier files re-run safely).
3. Open /admin/contacts. Edit one test account's WhatsApp, press Save, reload to see it kept. Then open /admin/audit and look for contact.view and contact.edit.
4. Optional: /admin/deploy-check has a new check for 0067 (expect 1, 0, 1).
The profile page keeps saving if the website goes live before the migration (the WhatsApp number just is not stored until 0067 runs).
