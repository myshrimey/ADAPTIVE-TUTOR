STEP-BY-STEP: WHAT TO DO
--------------------------
1. Copy every file in this zip into your real project folder, into the
   exact same folder paths shown (e.g. a file at
   `packages/db/migrations/0009_pilot_payments.sql` in this zip goes into
   `packages/db/migrations/` in your project — same as every previous
   round). Some of these are BRAND NEW files in brand new folders
   (apps/web/app/pilot, apps/web/app/report, apps/web/app/admin/payments,
   apps/web/app/legal, apps/web/app/contact, apps/web/content, and three
   new folders under packages/core) — just create those folders if they
   don't exist yet and put the files inside.

2. Open a terminal in your project folder and run:
     npm install
     npm run db:migrate
   What success looks like: no red error text. If you see "policy already
   exists," that's fine.

3. Then run:
     npm run build
   What success looks like: it ends with a list of routes (40 of them) and
   no red "Failed to compile" text. I already ran this exact build myself
   and it was clean — but please still run it yourself before pushing,
   since your real project may have small differences from mine.

4. Commit and push to GitHub the way you always have. Vercel will pick it
   up and deploy automatically.

5. Go through the smoke-test checklist in docs/DEPLOYMENT_GUIDE.md once
   it's live.
