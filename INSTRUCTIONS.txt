3. Admin > Audit log: who changed what.
4. Country picker on the Profile page (country, time zone and currency are saved).

STEPS
1. Unzip over your project folder (replace files).
2. Run: npm install
3. Run: npm run db:migrate   (adds migration 0038; safe to run twice)
4. Deploy as usual.
5. Open Admin > Financial simulator and enter your real numbers, especially the AI cost per student, tutor and centre (see Admin > AI Economics). If AI cost is left at 0 the results look better than they will be, and the page warns you. Press "Save these numbers".
