SAHAYAK v79 - Create accounts by invitation, admin team, Help. ONE database change (0049).
1. Unzip over your project, commit, let Vercel deploy.
2. Run: npm run db:migrate (adds 0049; safe to run again).
3. In Vercel > Settings > Environment Variables add NEXT_PUBLIC_SITE_URL = your website address (for example https://yourname.com, no slash at the end) so shared links point to the real site. Optionally add INVITE_SECRET = a long random text (without it the app uses your existing server key). Redeploy.
4. Admin > Customers & Growth > Users and accounts > "+ Add Tutor" (or Student, Parent, Teacher, Coaching Centre). Fill the details, press Create + share invitation. Copy the link or press Share on WhatsApp. The link is also always in Admin > Invitations.
5. Open the link in a private window to register as that person (role is fixed). Then look at Admin > Invitations for the status.
6. Admin > Admin team (you only): add a colleague by their sign-in email, pick Operations/Academic/Content/Marketing/Finance/Support/Technology or tick permissions.
7. Help is at /help (also in the footer and the account menu).
