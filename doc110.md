# v110 build summary - forgot-password through a limited server route (2026-11-08)

**What changed.** The sign-in page used to ask Supabase for the reset email straight from the browser: no limit, and the raw error text was shown. It now calls `/api/auth/forgot-password`.
- Limit: 5 requests per internet address and 3 per email per hour (one-way hashes in the existing `public_check_log`; no new table; fails open if the table is missing).
- The limit is checked before the reset is requested. Blocked = 429 with Retry-After.
- The answer is the same sentence whether or not the account exists. Errors stay in the server log.
- No migration. R60 / TASK-078 / EX-0022.
