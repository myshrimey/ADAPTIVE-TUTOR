# v142 - Live API boundary check (TASK-060)

A script you run from your own computer against the deployed site. It calls every API route found in the repo (144 routes, 171 route+method pairs) and reports who can get an answer.

Run: `node scripts/live-checks/api-boundaries.mjs https://your-site [--student-cookie "..."]`

Tiers: (1) signed out; (2) forged or expired session; (3) optional, a TEST student's cookie against admin, teacher, centre and portal routes. It never signs in and never prints the cookie. GET only reads; every other method is sent an invalid body so nothing changes.

Result: PASS, REVIEW (a route answered a signed-out caller with data: confirm it is meant to be public) or FAIL (5xx, no answer, role-only route leaking, /api/me showing a person). Exit code 1 on any FAIL.

Tested: t142 (18 checks) including an end-to-end run against a local stand-in site with planted holes; full suite 113 pass, 4 known-stale, 0 fail; type check clean.
Not tested: not run on the live site. Not built: other-account case (needs two test logins).
Details: docs/LIVE_API_CHECKS.md.
